# Wedding invitation website

A responsive single-page invitation inspired by the reference. Static HTML with embedded styles and scripts; no build step.

Before sharing, replace the bracketed couple names, venue/address, event times, dress code, FAQ answers, and RSVP deadline in index.html. Add your film as assets/our-film.mp4 and replace the sample image URLs with your own images. The included RSVP form is a preview only; connect it to a form service or endpoint to collect replies. Countdown currently targets 4:00 PM India time on 11 February 2027.

To publish, upload this folder's contents to a public GitHub repository. In Settings → Pages, select Deploy from a branch, choose main and /(root), and save. GitHub Pages will provide a public invitation URL.
